# SAW Method Implementation

A Decision Support System application for selecting high-quality *santri* (Islamic boarding school students) using the Simple Additive Weighting (SAW) method.

## Installation Instructions
1. Place the folder in `htdocs` (XAMPP).
2. Import `metode_saw.sql` via phpMyAdmin.
3. Copy `admin/assets/conn/config.php` and adjust the settings.
4. Open `http://localhost/penerapan-metode-saw`.
